マイアミのクラブで本物のIDを却下された女性が警察を呼ぶ：“覚えておいて、私はあと5か月で22歳”

POST LINE
マイアミのナイトクラブで実 ID が拒否されたと主張する女性が怒っており、状況を是正するため警察を呼んだと述べている。TikTok クリエイターの Mia（@mimuushkaa）がクラブからの動画を投稿。「今日は初めて実 ID を拒否された」と発言し、「警察を呼ばなければならなかった。今はこのバウンサーを謙虚にさせるのを待つ」と語る。キャプションには「私が22歳になるのは5か月後」を添える。ビデオのコメント欄では、現場の様子や未成年者の飲酒を防ぐ責任などへの反応が寄せられている。実 ID を持つ21歳以下の客を拒否する事例は過去にもあり、バーや酒類を提供する店舗は法的に年齢確認を義務づけられている。偽造IDの可能性が高い場合に厳格化する動きがある一方、正当なIDであっても入場を拒否されることはあり得るとする意見もある。AllHipHop は Mia にTikTokのコメントとダイレクトメッセージでコメントを求め、回答があれば記事を更新するとしている。
