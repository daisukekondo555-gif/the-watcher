ラリー・ジャクソンの Gamma が Ye（カニエ・ウェスト）関連の配信操作疑惑を巡る提訴へ

POST LINE
Gamma は、ラリー・ジャクソンが創業したエンタテインメント企業。オンラインでの coordinated な名誉毀損行為をめぐり、ニューヨーク州最高裁に訴えを起こした。匿名の運営者を特定することを求め、作品サイトと連携した虚偽の主張を公表したとしている。サイトは financial misconduct、streaming manipulation、investor funds の流用を含む虚偽で有害な主張を拡散したとされ、特に Ye の Bully アルバムの inflated streaming activity や投資家資金の私的航空機等への支出を主張している。サイト名は larryjacksonexposed.com と gammaexposed.com。Bloomberg の Jackson の影響力を詳述した好意的な特集掲載直後に出現したとされる。訴状には、Jackson が「最後の 1000万ドルのうち 1000万ドル未満」とするなどの主張や、「投資家資金を私的飛行機や贅沢な生活、個人PR、レガシーアーティスト契約に使い image と status を高めるために流用した」などの説明が含まれる。Gamma はこれらの主張を否定し、サイトは social media 全体の協調拡散キャンペーンの一部と主張。新規作成アカウント数百が連続的にリンクを拡散し、Reddit でも同様の情報が見られたが削除されたとする。担当調査員は匿名化されたホスティングと層状のオンライン保護により責任者の特定が不能と述べている。Gamma は損害賠償、サイトの削除、陪審裁判を求めている。
